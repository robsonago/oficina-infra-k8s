# oficina-infra-k8s

Infraestrutura Kubernetes (Terraform) do Tech Challenge Fase 3 (Pós-Tech SOAT).

Um dos 4 repositórios exigidos pelo desafio, responsável por provisionar o
cluster Kubernetes gerenciado (GKE) onde a aplicação principal
([`oficina`](https://github.com/robsonago/oficina)) roda, incluindo os
namespaces de homologação e produção.

> Repositório em construção — este README será substituído pela versão final
> com stack, instruções de execução, diagrama de arquitetura e link do
> ambiente ativo assim que a infraestrutura for provisionada.

Dockerfile não se aplica a este repositório (Terraform não usa Docker).
